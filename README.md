# 🍃 Banarasi Paan Website

A beautiful, modern, and responsive website for Banarasi Paan - the authentic betel leaf delicacy from Varanasi, India.

## 📄 Pages

- **Home** - Welcome page with hero section, features, and popular products
- **About** - Company story, timeline, team members, and core values
- **Products** - Complete product catalog with filtering and pricing
- **Benefits** - Health benefits, ingredients, and Ayurvedic perspective
- **Gallery** - Image gallery with categories and customer reviews
- **Contact** - Contact form, location info, FAQ, and newsletter
